# ViewModel---Activity

ViewModel es una libreria para Android Studio, con la cuál tu puedes guardar variables que perduran incluso despues de que ocurran cambios en pantalla, por ejemplo, al rotar la pantalla y pasarla de vertical a horizontal o viceversa, un valor que esté guardado en una variable de tipo ViewModel se va a mantener incluso despues de que la pantalla rotara, al igual que por ejemplo, se mantendrá el valor entre distintas pantallas/vistas.

**Cómo funciona la aplicación?**

En este ejemplo puedes sumar de uno en uno a una variable, y luego cambiar de pantalla para así comprobar como este valor se mantiene guardado.
